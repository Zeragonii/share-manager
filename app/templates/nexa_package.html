Provider package mapping

This is an opt-in entitlement on the existing Package, not a new billing tier. It does not create or extend IPTV accounts in Phase 2.

The NEXA lookup API does not report which package is currently on an existing account. Mapping here defines what Share Manager would use for future six- or twelve-month extensions, not what it has verified is installed today.

Safety and compatibility

Monthly billing buys the lowest supported six-month NEXA duration when an extension is due; yearly billing buys twelve months. These mappings do not affect existing Share Manager payment dates or customer access.

The provider package determines channel entitlements. Choose matching variants (including adult-content preferences and 4K access) before enabling the future renewal engine. Missing six-month variants must remain unmapped for monthly tiers.
