Database backup

The download is generated from the live PostgreSQL database using pg_dump in custom/compressed format. Creating it does not stop or modify Share Manager.

Download database backup
Restore

Restore into an empty Share Manager database with:

pg_restore --clean --if-exists --no-owner -d sharemanager share-manager-YYYYMMDD-HHMMSS.dump

Stop the Share Manager app while restoring, and take a fresh backup first. Your Docker/Portainer environment variables and stack definition are not stored inside the database dump.
