Use this after rebuilding the stack or when importing a backup copied from another machine. PostgreSQL custom-format .dump files are validated with pg_restore --list before anything is changed.

Storage warning

A backup on the same failed disk is not a disaster-recovery backup. In Portainer, set BACKUP_HOST_PATH to a path on your Unraid/NFS/other independent storage before relying on the schedule.

Automatic retention keeps the newest {{ retention_daily }} backups, plus one representative restore point from each of the newest {{ retention_weekly }} ISO weeks and {{ retention_monthly }} calendar months. Manual and pre-restore safety backups are never automatically pruned. Schedule and retention are configured above; the old BACKUP_* automation environment variables are now only first-run defaults.

The database dump contains Share Manager data, but not your Portainer stack environment variables/secrets. Back those up separately.
